# لوحة تحكم مواصلات

افتح `index.html` أو شغّل خادمًا محليًا: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

## التنظيم
- كل قسم له صفحة HTML مستقلة (`orders.html`, `providers.html`, `rides.html`، إلخ).
- `assets/style.css`: التنسيق المشترك.
- `assets/data.js`: بيانات العرض الأولية وأقسام التنقل.
- `assets/app.js`: عرض الصفحات والنماذج والبحث والفلاتر وحفظ التغييرات.
- تعرض جميع الصفحات بيانات تجريبية؛ تحفظ التغييرات في `localStorage`.

## ربط API
يمكن استبدال مصدر `db` في `assets/app.js` بطبقة API تعيد البيانات بحسب `page`. العمليات `save`, `openForm`, `removeRow`, و`updateStatus` هي نقاط الربط الأساسية. بيانات العرض الحالية ليست خادمًا ولا تعالج الدفع أو الإسناد المتزامن.
